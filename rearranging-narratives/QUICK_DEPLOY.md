# 🚀 快速部署指南

## 立即部署

```bash
cd rearranging-narratives
npm run deploy
```

就这么简单！

## 首次部署后

1. 访问：https://github.com/Zzyyyyyyyyyyyyyy/Corelab_Interactive_Archive/settings/pages
2. 在 **Source** 选择 `gh-pages` 分支
3. 点击 **Save**
4. 等待 1-2 分钟
5. 访问：https://zzyyyyyyyyyyyyyy.github.io/Corelab_Interactive_Archive/

## 每次更新

```bash
# 修改代码后
npm run deploy
```

## 完整流程

```bash
# 1. 提交代码
git add .
git commit -m "Update content"
git push

# 2. 部署
npm run deploy
```

完成！✨
